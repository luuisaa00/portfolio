# Planos para Peludos

Portfolio personal de una estudiante de Edificación / Arquitectura Técnica que, además, construye rascadores y plataformas para una asociación felina y cuida gatos y perros a domicilio.

La web está planteada como una obra en curso: plano azul, cartel de obra, fases de construcción y un rascador que monta una grúa torre.

## Estructura

```
index.html      contenido de la página
css/styles.css  estilos (paleta, tipografías, secciones)
js/main.js      animaciones e interacción
img/            fotos de rascadores y láminas
```

## Secciones

| Fase | Contenido |
|------|-----------|
| 00 Portada | Presentación, cartel de obra y plano animado |
| 01 Replanteo | Sobre mí |
| 02 Estructura | Proyectos de la carrera |
| 03 Instalaciones felinas | Rascadores y plataformas |
| 04 Mantenimiento | Cuidado de gatos y perros a domicilio |
| 05 Recepción de obra | Contacto |

## Tecnología

HTML, CSS y JavaScript sin frameworks. Publicado con GitHub Pages.
